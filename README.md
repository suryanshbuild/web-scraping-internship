# 📚 Web Scraping Using Python

## Internship Task 1

### Project Description

This project uses Python to extract book information from [Books to Scrape](https://books.toscrape.com/) and save it in a CSV file.

### Technologies Used

* Python
* Requests
* BeautifulSoup
* CSV

### Features

* Extracts book titles, prices, ratings, and availability.
* Supports multiple pages.
* Saves data in CSV format.

### How to Run

1. Install dependencies:

   ```bash
   pip install -r requirements.txt
   ```
2. Run the scraper:

   ```bash
   python scraper.py --pages 3
   ```

### Output

A CSV file containing the collected book data.
